# Data Files Directory

This directory contains input data files used by the application:

- `triangles.json`: Triangle coordinates formatted as JSON arrays of coordinate pairs.
- `triangles.csv`: Triangle coordinates in tabular CSV format with columns:
  - `triangle_id`: Unique identifier for the triangle (e.g. `t1`, `t2`, `t3`).
  - `x`: The x-coordinate of the vertex.
  - `y`: The y-coordinate of the vertex.
